# KitchenPanel

Open-source, low-power touchscreen kitchen assistant powered by ESP32.

## Vision

A self-contained, battery-powered, offline recipe companion with a seven-inch touchscreen and removable, suction-mounted, 3D-printable enclosure. The first use case is guided bread-maker recipes; future appliances should require no hardware redesign.

## MVP

- Browse a local recipe catalog and follow ingredient and preparation steps.
- Display appliance program and settings without controlling the appliance.
- Suspend or power off between uses and restore progress.
- Import custom recipes without cloud services.
- Assemble without soldering using verified compatible components.

## Status

Foundation phase. No firmware or mechanical design has been validated yet.

See [requirements](docs/requirements.md), [hardware plan](docs/hardware.md) and [journal](docs/journal/001-foundation.md).
